## 为什么 Vision Pro 玩家都在用 Hoho 3D？

入手 Apple Vision Pro 后，几乎每位影音玩家都会遇到三个真实痛点：
1. **3D 片源太少，95% 的日常片源都是普通 2D**：想看动漫、剧集、老电影、演唱会或自己拍的视频，却只能当普通平板窗口看，浪费了 Vision Pro 顶级的双目 4K Micro-OLED 屏幕。
2. **躺在床上看天花板时操作极度繁琐**：切下一集画面又跑回正前方、每次都要手动长按表冠重置视角；手放在被子上稍微动一下，进度条面板就误触弹出来挡住字幕。
3. **几十 GB 的 8K VR180 与蓝光 MKV 拷进头显太折腾**：局域网直连经常遇到音轨无声、MKV 内嵌字幕读不出，或者摘下头显后下载直接中断。

**Hoho 3D Player** 专为 Apple Vision Pro 原生打造，彻底解决以上三大痛点。

## 四大核心能力与体验亮点

### 1. 端侧 AI 实时 2D 转 3D + 100%–500% 微曲环抱巨幕（核心绝活）
* **自研端侧神经立体引擎**：无需在电脑端提前转码，在 Vision Pro 本机实时将绝大多数普通 2D 视频（电影、剧集、动漫、演唱会、游戏录屏、家庭回忆）转换为自然舒适的双目立体 3D。**没有 3D 片源，也能天天看 3D。**
* **「3D 沉浸」微曲环抱巨幕**：开启后自动隐藏现实房间干扰，画面化作微曲环抱巨幕悬浮于纯黑空间。支持 **100%–500% 真实 5 倍线性无级缩放**（最高可达 180° 环抱视野，竖屏视频同样解锁巨幕高度），配合光学柔化羽化边框，彻底告别生硬黑边。
* **三档景深强度与屏幕亮度调节**：支持在沉浸面板或设置中实时切换 **柔和 / 标准 / 深邃** 三档 AI 立体景深强度，并支持 **40%–100% 沉浸屏幕亮度调节**，深夜关灯看片依然护眼不刺眼。
* **发丝级边缘保护与零眩晕防抖**：内置自研跨帧时域稳定控制、前景边缘保护与航拍/大场景防漂移算法，画面锐利通透，久看两小时依然舒适不晕。

### 2. 原生空间视频、Apple Immersive Video 与 8K VR180 / 360° 全景
* **全制式 3D 与 VR 原生播放**：支持 **Apple 空间视频 (`MV-HEVC`)**、**Apple Immersive Video (`AIVU`)**、**180° 半球 (`VR180`)**、**360° 全景视频**，以及 **全宽/半宽左右 (`SBS`) 与上下 (`TB`) 3D 视频**。
* **毫秒级自动识别 + 播放器内一键兜底**：打开视频自动识别立体封装与投影规格；遇到命名不规范的视频，可在播放器内随时手动切换 `2D / 3D / VR180 / 360°` 及交换左右眼顺序。

### 3. 专为「躺平看片」打磨的零打扰操控体系
* **躺下即正对天花板视线**：进入播放（含列表连播自动切集）时，若检测到仰视角度超过 `35°`，巨幕自动平滑贴合当前躺姿视线，无需手动长按表冠；坐姿与平视则保持水平正前方。
* **坐姿 / 躺姿独立高度记忆**：在控制面板微调过的画面高度，会按坐姿与躺姿分别独立记忆，下次播放自动恢复。
* **重置视角不丢画面大小**：点击「重置视角」只将画面重新居中对齐视线，完整保留你调好的 `100%–500%` 巨幕缩放比例与高度偏移。
* **双击唤醒防误触 + 沉浸选集抽屉**：可在沉浸面板或设置中开启 **「双击唤醒控制面板」**，彻底告别手部微动误触弹窗；连播自动切集全程静默不弹面板；在沉浸空间内点击「选集」即可直接拉出播放列表抽屉无缝切集，拖拽进度条还支持**实时悬浮缩略图预览**。

### 4. NAS 与私人影院直连 + 摘下头显也能后台缓存
* **SMB / WebDAV / Emby / Jellyfin 全内置**：无需把几十 GB 的 8K VR180 大片拷进头显，直接浏览 Emby / Jellyfin 海报墙或 SMB / WebDAV 文件夹（自带**观看进度条、「已看完」标记与顶部「继续观看」横幅**）即点即播。
* **摘下头显锁屏续传**：通过 WebDAV（HTTPS）下载大型视频到本地离线库时，即使切换应用或摘下 Vision Pro，系统后台传输仍会继续完成。
* **广泛容器、多声道音频与 MKV 内嵌字幕直读**：直接播放 `MP4`、`MOV`、`MKV`、`M4V`、`WMV`、`AVI`、`TS`、`M2TS`、`WebM`，支持多声道音频、**MKV 内嵌文本字幕（`SRT` / `ASS` / `SSA` / `WebVTT`）一键提取切换**，以及增强型外挂字幕自动匹配（自动扫描同目录及 `Subs/`、`Subtitles/` 子目录）。
